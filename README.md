# drum-page
Interactive drum website that allows users to play drums directly through the keyboard, featuring real-time sound effects and a responsive design.

## 🎵 Deskripsi Project

**Drum Bass** adalah Project drum interaktif berbasis website yang memungkinkan pengguna memainkan berbagai suara drum hanya dengan menekan tombol pada keyboard.  
Proyek ini dibuat untuk melatih logic JavaScript, event handling, dan dasar-dasar interaksi audio di browser dengan tampilan yang simple, responsive, dan menarik.

---

## ⚙️ Fitur Utama

- ⌨️ **Interaksi Keyboard:** tekan tombol `W, A, S, D, J, K, L` untuk memainkan suara drum.
- 🥁 **Visual Feedback:** setiap tombol drum memiliki efek animasi saat ditekan.
- 📱 **Responsive Layout:** tampilan menyesuaikan ukuran layar (desktop, tablet, dan mobile).
- 🎨 **UI Modern:** desain clean dengan gradasi warna dan ikon drum yang menarik.

---

## 🧠 Teknologi yang Digunakan

- **HTML5** → untuk struktur elemen dan layout.
- **CSS3** → untuk tampilan visual, animasi, dan responsivitas.
- **JavaScript (Vanilla)** → untuk logika suara, event keyboard, dan efek interaktif.
